# 🚀 Para Ejecutar el Sistema

### 🟢 Paso 1: Crear la base de datos  
Crea la base de datos necesaria para el sistema desde tu gestor de base de datos favorito (phpMyAdmin, MySQL Workbench, etc.).

---

### 🟢 Paso 2: Iniciar Laragon con Apache  
Abre Laragon y asegúrate que el servidor **Apache** esté encendido (botón verde).

---

### 🟢 Paso 3: Abrir la terminal de Laragon y ejecutar el servidor PHP
1. Abre la terminal dentro de Laragon.  
2. Navega a la carpeta del proyecto con el siguiente comando:  
   ```bash
   cd C:\laragon\www\chatPHP
   php server.php
Paso 4: Abrir el proyecto en el navegador
http://localhost/chatPHP
