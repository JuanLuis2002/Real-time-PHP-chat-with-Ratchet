Para Ejecutar el sistema:
Paso 1 Crea la base de datos
Paso 2 Abre laragon con apache
Paso 3 ve ala terminal de laragon y coloca 
cd C:\laragon\www\chatPHP
luego coloca
php server.php
Paso 4 abre el proyecto con laragon apache en www y ya esta el sistema funcional
